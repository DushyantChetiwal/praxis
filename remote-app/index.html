Praxis Remote

Control Praxis on your laptop from your phone.

How to set this up
  1. Create a private GitHub repository, for example praxis-remote.
  2. Create a fine-grained personal access token:
    • Repository access: Only select repositories → your repository.
    • Permissions → Repository → Issues: Read and write.
    • Choose an expiration you're comfortable with.
  3. Turn on Remote in Praxis on your laptop, pointing at the same repository.
  4. Enter the repository and token above. They are stored only on this device.
