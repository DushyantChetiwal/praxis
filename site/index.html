Praxis — Plan-Driven AI Code Editor

Plan systems. Ship code. Praxis elevates planning from ephemeral chat prompts into an interactive Architect canvas with explicit steps, constraints, file surfaces, parallel Git worktree agents, and encrypted remote control from Android.

Architecture

Built for deterministic, multi-step engineering

Interactive Architect Canvas

Model complex tasks as an inspectable DAG of steps, rules, hand-off captures, branches, and bounded retry loops. Discuss individual nodes in dedicated step chats and resume safely from checkpoints.

Parallel Worktree Agents

Run independent sub-agents and concurrent plan branches inside isolated Git worktrees with static file-surface conflict checks, then review and merge clean diffs back to your primary checkout.

Non-Blocking Async Watchers

Long-running builds, CI watches, sub-agents, and Architect runs execute asynchronously and wake the parent conversation when they finish, fail, or need input—no wasted polling turns.

Native Rust & Multi-Agent ACP

Powered by Zed’s GPU-accelerated GPUI renderer. Use native Gemini, Claude, OpenAI, OpenRouter, or Ollama models alongside external ACP agents like Cursor, Claude Code, and Codex.

Praxis Remote for Android

Operate your desktop or headless Linux host from your phone

Pair once with a zero-server setup over encrypted WebRTC and Nostr relays. Inspect live streaming diffs and plan progress, approve permissions, switch models, answer agent questions, or steer runs by voice—even on headless WSL/SSH hosts paired directly from the CLI.

  • 0 ms startup with an on-device SQLite state cache
  • Sub-100 ms Protocol v3 delta streaming & lazy history
  • Interactive Plan, Sub-Agent, and Git Worktree inspector
  • No paid relay servers or cloud lock-in—end-to-end encrypted
